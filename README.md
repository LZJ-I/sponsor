# 赞助 / Sponsor

LZJ-I 开源项目共用的收款码。软件里点支付方式，弹出对应二维码。

Shared payment codes for LZJ-I projects. Apps show a QR when you click a payment method.

| 文件 / File | 渠道 / Channel |
| --- | --- |
| `wechat.webp` | 微信 / WeChat |
| `alipay.webp` | 支付宝 / Alipay |
| `afdian.webp` | 爱发电 / Afdian |

配置：[`sponsor.json`](sponsor.json)
